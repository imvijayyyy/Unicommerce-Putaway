BUILD WITHOUT ANDROID STUDIO (GitHub Actions)

This project now includes a GitHub Actions workflow at .github/workflows/build-apk.yml.

Important: A Gradle wrapper is required. This ZIP does not include the wrapper JAR because it must be generated by a Gradle installation. If the workflow fails with "./gradlew: No such file", add a Gradle wrapper to the project or use the online GitHub Codespaces/Gradle setup route. Do not install APKs from untrusted third-party build sites.

The source is an untested prototype. Even if it builds, test with one barcode first. It may need adjustment for Unicommerce's custom scan field and Enter handling. Accessibility access is powerful; enable it only for an app you trust.
